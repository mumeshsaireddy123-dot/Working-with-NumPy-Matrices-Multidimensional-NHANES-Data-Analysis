# Working-with-NumPy-Matrices-Multidimensional-NHANES-Data-Analysis
Project Summary — NHANES Adult Anthropometric Data Analysis

I completed an NHANES Adult Anthropometric Data Analysis project using Python and NumPy. The project focused on analyzing anthropometric measurements of adult male and female participants and understanding relationships between body measurements such as height, weight, waist circumference, hip circumference, and BMI.

During the project, I:

Loaded and processed the NHANES adult male and female datasets using NumPy.
Examined the structure and dimensions of the datasets.
Analyzed weight distributions using histograms.
Compared male and female weight distributions using boxplots.
Calculated important numerical statistics and aggregates for weight data.
Calculated BMI (Body Mass Index) for the female dataset and added it as a new column.
Standardized the female dataset using Z-score standardization.
Created and analyzed a scatterplot matrix to visually examine relationships between anthropometric variables.
Calculated Pearson and Spearman correlation matrices.
Investigated relationships between height, weight, waist, hip measurements, and BMI.
Extended the analysis to additional anthropometric measures, including BMI, WHtR (Waist-to-Height Ratio), and WHR (Waist-to-Hip Ratio).
Completed the later analysis tasks involving data manipulation, calculations, visualization, and interpretation.
Interpreted the results to understand which body measurements have stronger relationships with weight and BMI.

Tools/Technologies: Python, NumPy, Matplotlib, statistical analysis, data visualization, and CSV data processing.

Overall outcome: The project strengthened my practical understanding of NumPy arrays, data preprocessing, statistical calculations, standardization, correlation analysis, visualization, and interpretation of real-world health-related datasets.
